
# AI Video Assistant

An AI-powered application that helps users transcribe, summarize, and ask questions about video content using Generative AI and Retrieval-Augmented Generation (RAG).

## Features

- Video transcription using Whisper
- AI-powered video summarization
- Ask questions about video content
- Semantic search using embeddings and ChromaDB
- Context-aware responses using LLMs

## Tech Stack

- Python
- Streamlit
- Whisper
- LangChain
- ChromaDB
- Mistral AI
- FFmpeg

## Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/Abhishek-Kadam07/AI-Video-Assistant.git
   cd AI-Video-Assistant
   ```

2. Create and activate a virtual environment:

   ```bash
   python -m venv venv
   ```

   Windows:

   ```bash
   venv\Scripts\activate
   ```

3. Install dependencies:

   ```bash
   pip install -r Requirements.txt
   ```

4. Configure the required API keys using environment variables.

5. Run the application using the appropriate Python entry point.

## Purpose

This project explores video transcription, information retrieval, semantic search, and AI-generated summaries and answers.
